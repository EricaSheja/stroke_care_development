## Rules

* No colour coding, risk labels or alerts on readings.
* No emergency phone number on screen unless `docs/safety.md` lists it as verified.
* Say plainly which parts are built and which are planned.
* If the link has not loaded after 20 seconds, play the recorded video and say: this is the recorded run of the same build.
